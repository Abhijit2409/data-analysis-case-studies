# Issue Register — Repair and Refinement Pass

**Opened:** 2026-09-13 · **Baseline backup:** a full copy of the project taken before any change and kept outside this repository (`build/node_modules` excluded) · **Before screenshots:** `evidence/screenshots/before/`

> Outside-in portfolio project on public information and **synthetic** data. Every figure below comes from the synthetic dataset and is a test expectation, not a Specsavers result.

**Type:** **Defect** = reproduced behaviour that contradicts a documented requirement, rule or claim · **Inconsistency** = two project artefacts disagree · **Improvement** = suggested enhancement, no documented promise broken.
**Severity** uses the Phase 14 scale applied to the prototype: Sev 1 privacy/suppression bypass or harmful wrong data · Sev 2 core decision function wrong · Sev 3 workaround exists / non-core inaccuracy / usability · Sev 4 cosmetic or documentation.
**Test IDs** refer to the automated suites added in Phase E (`tests/`): `PY-*` Python calculation tests, `JS-*` Node logic tests, `UI-*` rendered-page regression tests (headless Edge), `DOC-*` document/deck checks. Status is updated at close-out (Section 4).
