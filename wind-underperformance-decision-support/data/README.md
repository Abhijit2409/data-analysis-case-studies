# Data

The raw data is **not** committed to this repository. It is publicly available
and about 140 MB unpacked. Download it before running anything.

## Source

ENGIE "La Haute Borne" wind farm, Meuse, France.

Published by ENGIE under the **Etalab Open Licence version 2.0**, which ENGIE
notes is designed to be compatible with Creative Commons Attribution 4.0.
**Credit ENGIE on any chart or slide that uses this data.**

The original ENGIE portal (`opendata-renewables.engie.com`) **no longer
resolves**, checked 30 September 2026. The OpenOA repository's own
`examples/data/readme.md` still links to it. The working copy is the one bundled
with OpenOA, used here.

## Download

```bash
curl -sSL -o data/raw/la_haute_borne.zip \
  "https://github.com/NatLabRockies/OpenOA/raw/main/examples/data/la_haute_borne.zip"
```

Then extract into `data/raw/`, skipping the `__MACOSX/` entries that macOS adds
to zip files.

## Important: some fields are synthetic

The OpenOA import script
([`examples/project_ENGIE.py`](https://github.com/NatLabRockies/OpenOA/blob/main/examples/project_ENGIE.py))
states in its own source comments that:

- the meter series was *"generated by adding artificial electrical loss and
  uncertaitny to SCADA data"* (the typo is in the original), and
- curtailment and availability were *"generated by estimating availability and
  curtailment from SCADA data"*.

The Phase 1 audit tested both claims against the files and found them consistent
with the data. See `docs/phase_1_findings.md`.

**Consequence:** `net_energy_kwh`, `availability_kwh` and `curtailment_kwh` may be
used for internal consistency checks only. They are **not** independent evidence
of exported energy, availability or curtailment, and must not be presented as
such.

## Units

From `SCADA_data_description.csv`:

| Column | Meaning | Unit |
|---|---|---|
| `P_avg` | Active power | kW |
| `Ws_avg` | Wind speed | m/s |
| `Ot_avg` | Outdoor temperature | deg C |
| `Ba_avg` | Pitch angle | deg |
| `Ya_avg` | Nacelle angle | deg |
| `Wa_avg` | Absolute wind direction | deg |
| `Va_avg` | Vane position | deg |

Note: the description file also lists `Rm` (torque) and `Ds` (generator speed),
but **neither column is present** in the SCADA file.
