Definition

Outside-in portfolio prototype built on fictional synthetic data (seed 20260913). Definitions, thresholds, peer rules and prompts are illustrative proposals (KPI dictionary v0.2, exception rule set v0.2, prompt library v0.2), not Specsavers definitions, targets or results. Responsive and keyboard behaviour were checked with automated and manual tests; no formal accessibility audit has been carried out.
